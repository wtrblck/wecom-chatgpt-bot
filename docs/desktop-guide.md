# WeChatGPT 桌面工作台

运行 Windows 10/11 x64。完整解压程序包后双击 WeChatGPT.exe；EXE 和 app 文件夹须一起保留。程序包包含 .NET、Node.js、Python 与 Chromium，无需另装开发环境。

## 第一次使用

1. 手动登录 Windows 微信，保持主窗口可用，并打开一个聊天窗口。
2. 在工作台点击“检测环境”。“已登录”和“当前控件可用”是两项独立检查。
3. 打开“监听会话”，添加准确且唯一的群名或联系人名称。按需填写稳定微信 ID，启用需要自动回复的会话。
4. 默认支持 /gpt、@ChatBOT 和 @chatbot，在后面加一个空格再输入问题，例如“@chatbot 简单解释一下黑洞”。这些是消息正文的文本前缀。可在“触发词别名”里用逗号分隔增删，也可关闭前缀限制。
5. 在“回答风格”填写“全局回复风格”。需要固定称呼或结尾时，在“回复固定格式”单独填写前缀和后缀（例如“主人”和“喵”），点击“保存全部设置”。
6. 点击“登录 / 打开 GPT”，在专用 Chromium 窗口里手动登录。账号标记得到验证后显示“已登录”；仅发现输入框时不会据此判定登录。
7. 点击“启动机器人”。首次打开 UI 不会自动启动或发送消息。修改设置时先“安全停止”，保存后再次启动。

## 配置与数据

- 在本项目的 release/WeChatGPT 目录中直接启动时，自动识别并复用两级上方的项目（现有 .env、登录资料、数据库与监听配置）。
- 把完整程序包移动到其他目录或另一台电脑时，使用随包 app 目录，首次需重新配置会话并登录 GPT。
- 可通过 WeChatGPT.exe --project "E:\完整项目路径" 显式指定项目。不能同时用多个机器人操作同一份数据。
- 桌面设置保存在 data/desktop-settings.json，一次性校验并原子替换。它覆盖 .env 中的触发词、轮询/发送间隔、发送动作，以及旧文件中的监听列表。旧配置文件仍保留。
- 首次未保存桌面设置时，会从现有项目配置读取会话与运行参数。
- 每个新 GPT 对话先单独发送一次长期指令：“接下来，我会和你进行一系列聊天……”，其中包含全局风格、群聊补充要求和固定格式。等待网页确认后再发送实际问题，初始化确认不会转发到微信。后续只发送去掉触发词的消息正文，重启后仍复用已保存的对话，不重复初始化。网页没有 API system 角色，语气仍由模型决定；固定前后缀由程序在保存生成回答前补齐，已有时不重复添加。群内 @ 提醒位于正文之前，命令与错误提示不添加前后缀。旧设置默认不启用固定格式。
- 使用“触发词 + /new”开始新对话，例如 `/gpt /new`、`@ChatBOT /new`、`@chatbot /new` 或你配置的别名加 `/new`。也可在 UI“监听会话”页选中一行，点击“新建 GPT 对话”。只重置该会话的 GPT 上下文关联，下一条问题到来时创建网页对话并初始化风格，不删除历史数据库或其他群的上下文。UI 支持机器人停止时或该会话无未完成问题时操作。
- 修改风格后，先保存并重新启动机器人，再使用上述任一方式切换新 GPT 对话。已存在的旧对话不会自动插入新版指令。
- EXE 关闭时等待机器人完成安全清理，不会自动强制终止。未保存的编辑会在关闭前提示。
- “今日完成回答”统计今天保存的 GPT 回答；“需要核对的分片”来自发件箱，不代表对方已经收到。
- 日志页显示本次桌面会话最近 200 条运行事件。机器人完整日志在 latest.log；导出的诊断报告不含群名、ID、提示词、登录资料或聊天记录。

## 兼容性与排障

微信控件检查基于当前打开的聊天窗口。客户端更新、最小化、切换窗口或可访问性变化都可能影响检测结果，请重新检查；发送时仍会核验目标和输入框。

已修复宽窗口或最大化时聊天标题核验失败：优先定位微信专用的当前聊天名称控件，并精确比较目标名称；仍拒绝重名、隐藏或不匹配的目标。日志中先前的失败记录会保留，更新不会自动补发失败回答。

若“兼容性待确认”，请先登录并还原微信、打开聊天窗口，再重新检测。仍无控件时，参阅项目 docs/wechat-delivery-capabilities.md。桌面界面不会自动修改微信进程或启用旧式坐标发送。界面中的发送快捷键须与微信设置一致。

消息读取依赖检查只验证本地依赖能否加载；真正的微信数据库连接在启动机器人时验证，错误会显示在运行记录。GPT 登录也必须在程序专用浏览器中完成，其他浏览器里的登录不会自动迁移。

如果发现命令行机器人运行中，请先在项目中运行 npm run stop，再从桌面接管。未知发送状态请在微信人工核对，不要直接重复发送。

## 从源代码构建

项目依赖安装完成后运行 npm run desktop:build。开发运行使用 npm run desktop:dev。

构建产物位于 release/WeChatGPT/WeChatGPT.exe，便携 ZIP 位于 release/WeChatGPT-1.1.0-win-x64.zip。发布包不包含本项目的真实账号、浏览器资料、聊天历史或监听对象。
